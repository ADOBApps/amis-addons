# UNet++

AMIS addon `unetpp` (learned).

Zhou et al. (2018) UNet++: nested, densely connected decoder pathways that narrow the semantic gap between encoder and decoder features.

## Install

```bash
python -m amis.market install unetpp
```

or copy this folder into the AMIS addons directory and press *Reload addons*.
