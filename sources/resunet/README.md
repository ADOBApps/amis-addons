# ResUNet

AMIS addon `resunet` (learned).

Residual U-Net: residual convolution blocks with identity shortcuts in both encoder and decoder, which trains deeper stacks without vanishing gradients.

## Install

```bash
python -m amis.market install resunet
```

or copy this folder into the AMIS addons directory and press *Reload addons*.
